# Paper draft

ACL-format LaTeX source (`acl.sty` and `acl_natbib.bst` from
acl-org/acl-style-files @ `d5adc82`).

Build: `tectonic main.tex` (tested with Tectonic 0.17.0), or `pdflatex main && bibtex main && pdflatex main && pdflatex main`,
or upload this folder to Overleaf.

Red `[...]` markers (`\pending`) are results not yet produced: the preregistered
confirmatory test (`docs/confirmatory_preregistration.md`). Every other number
comes from the results summaries in `docs/`. `figures/mddre_cost_quality_curves.pdf`
is `docs/figures/mddre_cost_quality_curves.svg` converted with `rsvg-convert -f pdf`.
Bibliography entries for ACL Anthology papers are the Anthology's own BibTeX.
